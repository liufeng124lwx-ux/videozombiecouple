# 站点前端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从 UnblurPix 的 Astro 站点复制骨架，换成丧尸情侣故事站：独特的「冷夜 + 余烬金」电影海报风格、Grade Wipe 签名交互、两张照片上传 → 免费关键帧预览 → 次数包付费 → 渲染进度 → 播放下载的工具岛、首页与落地页的 SEO 内容、价格页、故事页、账户页、法律页；构建检查与 CI 通过。

**Architecture:** `apps/web` 是 Astro 5 静态站 + Preact 岛（沿用 unblurpix 的 catalog 驱动页面、MDX 内容、`{{key}}` 数字插值、SEO / sitemap / OG / check-dist）。删除图片工具专用代码（工作台、编辑器、本地工具、GIF、诊断、对比画布），保留登录对话框、购买按钮、账户面板、埋点、同意横幅、Turnstile / human-pass、人脸检测（MediaPipe）、图片解码与 JPEG 重编码。新增 `StoryTool` 岛（状态机驱动）和 `GradeWipe` 组件。

**Tech Stack:** Astro 5.18、Preact 10、MDX、Vitest + Testing Library、Playwright（browser-check / e2e）、Lighthouse、satori + resvg（OG 图）、`@fontsource-variable/archivo`、`@fontsource/courier-prime`、`@fontsource/cormorant-garamond`、MediaPipe tasks-vision。

**Spec:** `docs/superpowers/specs/2026-10-14-videozombiecouple-design.md`（§6 页面与 SEO、§7 计费、§8.1 合规）；设计锁：`docs/design/research-2026-10-14.md`（Reference lock、页面结构、工具状态、Decision ledger、Grade Wipe）。

## Global Constraints

- 视觉 token（不得替换角色）：`--bg #0B0F14`、`--surface-1 #121921`、`--surface-2 #1A232D`、`--hairline #26313D`、`--bg-warm #120D09`；文字 `#E6ECF2 / #8C9DAE / #5B6B7B`；唯一强调色余烬金 `#F0A040`（hover `#F5B460`，其上文字 `#1A1006`），**只**用于主按钮填充、进度填充、选中描边；记忆光 `#FFD49A → #E8873A` 只用于暖色画面上的光晕与片尾字幕卡；错误 `#E5484D`。
- 字体：Archivo 可变（标题宽 62、字重 800、全大写、字距 −0.02em、行高 0.9；正文宽 100、400/600）；Courier Prime 只用于场景标头 / 时间码 / 标签（12px、大写、字距 +0.08em）；Cormorant Garamond 斜体只用于片尾字幕卡。
- 圆角：按钮 / 输入框 2px，图片与画框 0，选择芯片 999px；无阴影（模态框除外）；纵深靠表面层级与 1px 细线。
- 胶片颗粒：SVG `feTurbulence` 5% 透明度覆盖层，移动端静态，`prefers-reduced-motion` 关闭。
- 禁止：感染绿、紫 / 靛蓝光晕、Netflix 红、渐变按钮、毛玻璃卡片、滴血字体、Inter / Bricolage、标题单词换衬线或换色、奶油色背景、≥12px 圆角卡片、带图标的三栏特性网格。
- 每页只有一个 H1，等于 catalog 中该页 `h1`；首屏 H1 与副标题第一帧可见（LCP，不做淡入）；循环动画只用 `transform` / `opacity`；首屏以下区块 `content-visibility: auto`。
- 页面上的数字（价格、次数、额度、时长、保留期）只经 `{{key}}` 或 `<F k=… />` 从 catalog 读取。
- 移动端 PageSpeed ≥ 95、CLS = 0；首屏图片为一张 ≤ 90KB 的 AVIF 海报（`fetchpriority=high`）；视频 `preload="none"`，进入视口或点击后才加载。
- 样片只用评测生成的 AI 合成人物（`eval/data/personas` 与其关键帧 / 成片），不放真实用户作品。
- 收款用 Waffo（不是 Stripe）；不卖订阅。

## Review Focus

1. **上传的不是可读图片（HEIC、损坏文件、超大图）**：给出可读的错误，不进入预览，不消耗额度。→ Task 5 测试 `rejects unreadable photos before upload`。
2. **一张照片里有 0 张或 2 张以上人脸**：在本地就提示「需要一张正脸」，宠物版对第二张不检测人脸；检测器加载失败时放行（服务端还会检查）。→ Task 5 测试 `face check blocks zero or many faces`。
3. **预览 / 渲染中用户刷新或离开页面**：回来后从 `localStorage` 的 storyId 恢复轮询，不重复建故事。→ Task 5 测试 `resumes a running story after reload`。
4. **余额不足时点「生成视频」**：直接展开次数包选择并跳 Waffo 结账，结账返回后自动继续渲染（同一 storyId，幂等键不变）。→ Task 5 测试 `buys a pack then renders on return`。
5. **视频生成失败**：明确说明积分已退回，并提供「再试一次」；不显示空播放器。→ Task 5 测试 `shows refund message when the video fails`。
