# 设计调研（Refero，2026-10-14）

> 收款用 Waffo（不是 Stripe）；下文 Paying 状态中的 "Stripe Checkout" 读作 Waffo 结账。

I've finished the research. My main call is to drop "infection green" and make the single accent a warm ember gold, used only for buttons and progress, so the site's colour carries the cold-blue-to-warm-gold contrast instead of adding a third hue.

## 1. Research summary

**Styles** (6 searches: cinematic poster, horror/thriller streaming, A24 editorial, AI video landing, romantic warm editorial; 4 pulled in full):
- **NEON Rated**: dark film stills at full width, condensed, tightly set headlines that read like movie title cards, compact spacing, one restrained accent, outlined components with few fills. This is the base.
- **Letterboxd**: dark greys with a blue tint (#14181c family) arranged as a ladder of text shades, plus a strict rule that the one vivid colour appears only on main buttons. Square-ish 3px corners.
- **A24**: sharp corners, outline-only secondary buttons, a monospace face for metadata, lists divided by thin lines instead of cards.
- **Suno**: grainy, hazy texture on a dark canvas. I take only the texture. Its pink-to-yellow gradient button and 12px rounded cards are rejected.
- Seen but rejected: Krea, Morphic, Frame.io, Uizard, Superwhisper (generic dark AI tool with blue or violet glow); Netflix and HBO (poster collage plus red is a streaming cliché).

**Screens:**
- Visual Electric and Meiro: two results side by side to compare and pick.
- Synthesia, Luma, Runway: progress overlays with a percentage, a time estimate and a queue.
- OpenAI credits: stacked radio options, one full-width buy button, a price note.
- Steel: a buy-credits modal with a total summary.
- Open credit store: credit packs, no subscription.
- Doji, Hims, Meta AI: photo requirement checklists and a retake/confirm step.

**Flows:**
- **TikTok "AI Self Creation" (2796, 21 steps)**: consent screen with privacy notes → guided capture → retake or generate → queued with a time estimate ("You're up next") → percentage progress you can leave and come back to, plus cancel → results that go from blurred to sharp → pick → share.
- **Leonardo 12891 / Runway 1374**: generate → review → export, with a clear "saved" confirmation.

## 2. Reference lock

**Primary direction:** NEON Rated, adapted into a dark, cold-graded film poster.

**Preserve:**
1. Large film stills with condensed, tightly set headlines over them.
2. Compact spacing, outlined components, no stacks of cards.
3. A cold-graded canvas that is never pure black.
4. A single accent, used sparingly.
5. Images do the emotional work; the UI stays quiet.

**Borrow only:**
- Letterboxd's blue-tinted grey ladder and its "accent only on the main button" rule. NEON never fills buttons; we do fill the main one, because it has to convert.
- A24's monospace metadata. We use it as screenplay scene headings, e.g. `EXT. LIGHTHOUSE — NIGHT`.

**Role rules:**
- Ember gold is only for the main button fill, progress fill and the selected state.
- The memory glow is decorative only, on warm imagery and the end title card. It never goes on UI.
- The serif is only for the end title card (names and date), which is a literal title card in the video.
- The monospace face is only for scene headings, timecodes and labels.

**Media strategy:**
- All imagery is real model output: 9:16 frames graded cold or warm.
- First screen: one AVIF poster, 60–90 KB or less, with `fetchpriority=high`.
- Video is a `<video preload="none">` with a poster image. It starts loading when scrolled into view after the largest paint, or on tap.
- On mobile the H1 sits above the poster, so the largest paint is text.
- Grain is code only: an SVG `feTurbulence` overlay at 5% opacity, static on mobile, turned off for reduced motion.

**Reject:**
- Infection green. It adds a third hue, reads as Halloween slime, and duplicates Letterboxd/Metaview. This overrides the earlier idea.
- Violet or indigo glow, Netflix red, gradient buttons, glassmorphism cards.
- Drippy horror fonts, blood, purple and orange Halloween palettes.
- Inter and Bricolage (the sibling site uses them).
- One word of the headline set in a different serif or colour.
- Cream editorial backgrounds, 12px+ rounded cards, three-column feature grids with icons.

**Token commitments:**
- **Backgrounds:**
  - `--bg` #0B0F14 (cold night)
  - `--surface-1` #121921, `--surface-2` #1A232D
  - `--hairline` #26313D (1px)
  - Final warm section only: `--bg-warm` #120D09
- **Text:** `--text` #E6ECF2 (cool white), `--text-2` #8C9DAE, `--text-3` #5B6B7B. Text on the accent is #1A1006.
- **Accent, ember gold #F0A040:**
  - Fill on the main button, progress fill, selected outlines.
  - Hover #F5B460.
  - Never used for headings or decoration.
- **Secondary warm, memory glow:**
  - Colours #FFD49A → #E8873A.
  - Only as a light leak or gradient over warm frames and the end title card.
- **Error:** #E5484D, small and inline.
- **Type:**
  - **Archivo, variable** (Google Fonts, width 62–125, weight 100–900), one file.
  - Display at width 62, weight 800, uppercase, tracking −0.02em, line height 0.9.
  - Body at width 100, weights 400 and 600.
  - **Courier Prime** 400 for scene headings: 12px uppercase, +0.08em.
  - **Cormorant Garamond** 500 italic, end title card only.
- **Mobile type scale:**

  | Role | Size / line height |
  |---|---|
  | H1 | 52/0.9 (`clamp(52px, 11vw, 120px)`) |
  | H2 | 34/0.95 (up to 64) |
  | H3 | 20/1.2 |
  | Body | 16/1.55 |
  | Small | 14/1.45 |
  | Scene heading | 12 |
  | Button | 16, weight 600 |

- **Corners:** buttons and inputs 2px; film frames and images 0; selection chips only 999px.
- **Shadows:** none, except the modal (`0 1px 10px rgba(0,0,0,.35)`). Depth comes from surface steps and thin lines.
- **Film treatment:** grain at 5%, a 2.39:1 letterbox crop on wide desktop stills, a slight vignette on cold frames.

## 3. Structure

**Homepage.** The page background warms as you scroll, so the page itself plays the film from cold to warm.
1. **Nav:** wordmark, Pricing, an outlined "Make yours" button.
2. **Hero (cold):**
   - Scene heading `EXT. CABIN — NIGHT`, then the H1 (e.g. "Your zombie love story, starring the two of you").
   - Subline: 2 photos → 12s 9:16 film.
   - Main button: "Get a free preview".
   - Trust line: Free 2-frame preview · No subscription · Photos auto-deleted.
   - A 9:16 poster with the Grade Wipe (section 5).
3. **Three beats:** Standoff → Embrace → Memory as a sideways-scrolling filmstrip of 9:16 frames, with the colour shifting cold to warm along it.
4. **"Will it look like us?":** rows of three images (source photo → standoff frame → memory frame) for 2 couples and 1 pet. States plainly that you see 2 frames before paying.
5. **Choose your scene:** three scene posters, each split into cold and warm halves. Tapping one opens the tool with that scene already selected.
6. **Pet version:** one band.
7. **How it works:** three numbered rows divided by thin lines (A24), not cards.
8. **Pricing:** three packs as rows that look like ticket stubs, 3-pack marked "Most picked", price per video shown.
9. **Privacy and FAQ:** a line-divided accordion.
10. **Closing (warm canvas):** a live end title card ("Alex & Sam — since 2019") with the main button.
11. **Footer.**

**Tool states.** Single column, with a sticky bottom action bar.
1. **Empty:**
   - Human / Pet toggle.
   - Two 3:4 upload slots labelled `THE SURVIVOR` and `THE ONE WHO TURNS`.
   - Photo checklist with good/bad thumbnails (Doji, Hims): front-facing, one face, good light, no sunglasses.
   - Privacy line (TikTok consent pattern).
   - Bar shows a disabled "Add 2 photos".
2. **Photos added:**
   - Each slot shows the photo, a "Face found ✓" or warning message, and a Replace option.
   - A swap button between slots, since who turns matters (Hims retake/confirm pattern).
3. **Options:**
   - Scene picker as three 9:16 radio tiles.
   - Collapsed "Add end title": names and date, with a live preview of the title card.
   - Bar shows "Generate free preview".
4. **Preview generating:**
   - Two empty 9:16 frames that go from blurred to sharp (TikTok step 14).
   - A thin gold progress line.
   - Stages written as scene headings ("SC.01 Grading the night…").
   - "Safe to leave" note; the job is kept in localStorage.
5. **Preview ready:**
   - `STANDOFF` and `MEMORY` frames side by side (Visual Electric/Meiro), watermarked.
   - "Does this look like you?" with "Yes, make the film" (main button) and "Try other photos" (outlined, 2 free retries).
6. **Paying:**
   - Stacked radio pack rows (OpenAI credits), 3-pack preselected.
   - Total summary (Steel).
   - Stripe Checkout. Note: "One-time. No subscription."
7. **Rendering:**
   - Time estimate plus "You're up next" (TikTok), and an optional "email me when it's ready".
   - A `00:00 → 00:12` timeline whose fill is the Grade Wipe moving across the preview frame.
8. **Done:**
   - 9:16 player, muted autoplay, tap for sound.
   - Download MP4 (main button), Share via the phone's share sheet.
   - Ready-to-copy caption and hashtags, "Make another (2 left)", and "Delete my photos now".

## 4. Decision ledger

| Decision | Source | Role | Why |
|---|---|---|---|
| Condensed poster headlines over film stills | NEON Rated | H1/H2 | Film-billing energy, not SaaS |
| Blue-tinted dark greys #0B0F14 | Letterboxd + brief | Canvas = apocalypse | Carries the cold half of the colour device |
| One ember gold accent, buttons/progress only | Letterboxd rule + brief | Action = going toward the memory | Warmth means action; keeps a clear focus |
| Drop infection green | anti-slop / research | — | Third hue, Halloween feel, already used elsewhere |
| Archivo width 62/100 | NEON (condensed) + one-font rule | Display + body | One file, fast, different from the sibling's Inter |
| Courier Prime scene headings | A24 mono metadata | Labels and stages | Screenplay voice, has a real job |
| Serif only on end title card | Content role | Names and date | It is a literal title card, not decoration |
| 0–2px corners, thin lines, no cards | A24 / NEON | All components | Sharp, cinematic look |
| Grain overlay in code | Suno texture | Atmosphere | Film feel with no image weight |
| Two frames side by side + "looks like you?" | Visual Electric, Meiro | Preview ready | Answers the identity objection before payment |
| Queue, time estimate, safe to leave | TikTok 2796, Synthesia, Luma | Generating/rendering | Lowers anxiety while waiting |
| Radio pack rows + single buy button | OpenAI, Steel | Paying | Clear one-time pricing |
| Consent and photo checklist up front | TikTok, Doji, Hims | Empty state | Privacy and input quality |

## 5. Signature move: the Grade Wipe

Every 9:16 frame of the couple has a thin vertical line, a 1px gold hairline with a soft glow. On its left is the cold, blue standoff frame; on its right is the warm, golden memory frame of the same couple. This is the video's match cut, turned into an interface element.
- **Hero:** the line slowly drifts across on its own; you can also drag it.
- **Scene picker:** each tile shows the split.
- **Preview ready:** the user's own two frames sit inside the wipe.
- **Rendering:** the line's position is the progress bar, so the frame warms as the film renders.

The scroll-driven warming of the page background is the same idea at page scale.
